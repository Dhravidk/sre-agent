# Ally connector and service checklist

Use this as the integration inventory, not as a claim that Ally access exists. All Ally endpoints, resource identifiers, identities, policies, and acceptance results are **unknown until provided and verified**. Record sensitive completed values/evidence in an approved private system. Commit only sanitized contracts, configuration examples, code, and tests.

The requested production scope uses Dynatrace, ServiceNow, Teams, GitLab, Jira, and Confluence for context, with both provider-event and Teams-request intake. Source-system writes are a future extension; selective agent-requested Teams messages are in scope. GitHub remains an existing alternative, not a requirement of this ticket. The actual ServiceNow transport and enterprise contracts still require verification.
